プライバシーポリシー(tenki-yomikata-upload)

制定: 2026年10月28日

tenki-yomikata-upload(以下「本アプリ」)は、YouTube チャンネル「Tenki Yomikata」(@tenkiyomikata)の運営者が、 自分のチャンネルに自分で作った動画を投稿するためだけに使う、非公開の自動投稿の道具です。運営者以外の人がログインして使うことはありません。

1. 使う Google のデータ

本アプリは YouTube Data API(権限 https://www.googleapis.com/auth/youtube.force-ssl)で、運営者自身のチャンネルについて次のことだけを行います。

  • 動画のアップロードと、題・説明・公開範囲・合成コンテンツの開示などの設定
  • アップロードした動画の処理状況・公開状態の確認
  • チャンネル ID・チャンネル名・アップロード済み動画の一覧と投稿時刻の確認(投稿の本数の上限を守るため)

視聴者・他の利用者の個人情報、Gmail・連絡先・ドライブなど YouTube 以外の Google のデータには触れません。

2. 保存

認可の情報(更新用のトークン)は、運営者が管理する計算機の上の、運営者だけが読めるファイルに保存します。動画の投稿の記録(動画 ID・題・投稿時刻)は、運営者の作業記録として保存します。

3. 第三者への提供

本アプリが得た Google のデータを第三者に販売・提供・共有することはありません。広告にも使いません。

4. 取り消し

本アプリへの許可は、Google アカウントの サードパーティのアクセス の画面からいつでも取り消せます。取り消すと本アプリは投稿できなくなります。

5. 関連する規約

本アプリは YouTube API サービスを使います。YouTube 利用規約 と Google プライバシーポリシー も適用されます。

6. 連絡先

このページの置き場の GitHub の Issues から連絡できます。
